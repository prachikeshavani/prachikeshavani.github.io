## What I did today

- 🏗️ Built my personal website from scratch with **Hugo** and the **Doks** theme
- 🚀 Deployed it to **GitHub Pages** with an automated GitHub Actions workflow
- 🐉 Added a dragon favicon, because branding matters
- ✍️ Wrote my bio and Start Here page

## What I learned

How static site generators work: write Markdown → Hugo builds HTML → GitHub Actions deploys it on every push. Also learned that picking a theme is the hardest part (took me three tries).
